FILE SUPPORT & SCHEDULING
─────────────────────────────────────────────────────────────────────────────
TXT Files (Pipe-Delimited):
  • Pattern: BATCH_YYYY-MM-DD-HH:MM:SS.txt
  • Delimiter: | (pipe symbol)
  • Reader: txtItemReader (ItemReaderConfiguration)
  • Schedule: 20:00 IST (8:00 PM) - Cron: 0 0 20 * * ?
  • Status: ✅ Implemented

CSV Files:
  • Pattern: BATCH_YYYY-MM-DD-HH:MM:SS.csv
  • Delimiter: , (comma)
  • Reader: csvItemReader (ItemReaderConfiguration)
  • Schedule: 20:30 IST (8:30 PM) - Cron: 0 30 20 * * ?
  • Status: ✅ Implemented

XLSX Files (Excel):
  • Pattern: BATCH_YYYY-MM-DD-HH:MM:SS.xlsx
  • Parser: Apache POI 5.3.0 XSSFWorkbook
  • Reader: xlsxItemReader + ExcelFileReader
  • Schedule: 21:00 IST (9:00 PM) - Cron: 0 0 21 * * ?
  • Status: ✅ Implemented
